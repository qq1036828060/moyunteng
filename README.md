# 魔云腾云机容器调度平台前端

本分支为前端工程，基于 RuoYi-Vue3 改造，用于管理魔云腾主机、安卓容器资源池、任务调度、WebRTC 控制和 SDK 调用日志。

原若依说明文档已保留为 `README_RUOYI.md`。
