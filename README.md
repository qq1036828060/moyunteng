## WebRTC 播放器部署

控制页会请求后端 `GET /cloud/my/container/{containerId}/webrtc` 获取播放参数。后端会先同步魔云腾 SDK 容器状态，并按同主机同实例位做控制准备：

- 当前实例位没有可控制云机时，页面展示错误提示。
- 当前云机已启动时，直接进入控制。
- 当前云机未启动时，后端自动启动当前云机。
- 同实例位已有其他运行云机时，后端先关闭其他运行云机，再启动或保留当前云机。

容器运行中时，控制页默认打开：

```text
/webplayer/play-myt.html?shost={hostIp}&sport={tcpPort}&q=1&v=h264&rtc_i={hostIp}&rtc_p={udpPort}
```

需要将魔云腾官方播放器静态文件部署到前端：

```text
public/webplayer/play-myt.html
public/webplayer/js/...
public/webplayer/public/images/...
```

当前仓库已提供 `public/webplayer/play.html` 兜底入口，用于兼容旧链接并避免 iframe 404。该页面会优先检测同目录下是否存在官方 `play-myt.html`，存在时自动携带查询参数跳转；不存在时展示播放器未部署提示。

如果播放器静态文件部署在独立服务，可在前端环境变量中配置：

```text
VITE_APP_WEBRTC_PLAYER_BASE = 'http://your-player-host'
```

配置后控制页会打开 `{VITE_APP_WEBRTC_PLAYER_BASE}/webplayer/play.html?...`。当前已确认 `192.168.137.63:8000` 是魔云腾 SDK API 服务，不提供 `/webplayer/play.html` 静态页面。
